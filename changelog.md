# Changelog

## 2026-11-25

- Для администратора добавлена отдельная кнопка удаления у каждого сообщения в чате.
- Кнопка доступна только после проверки ключа администратора на сервере.
- Ключ администратора сохраняется в браузере для работы как из панели управления, так и из чата.
- Добавлена проверка распознавания администратора и удаления сообщения через API.

## 2026-11-06

- Сохранение позиции чтения в каждой комнате отдельно для логина и комнаты в браузерном хранилище.
- При повторном входе загрузка сообщений вокруг последнего видимого сообщения и восстановление прокрутки к нему.
- При отсутствии сохранённого сообщения или удалении сохранённой отметки загружается последняя история комнаты.
- API сообщений поддерживает загрузку последних сообщений по умолчанию, выборку после указанного ID (`after`) и выборку до указанного ID (`around`).
- Добавлены API-проверки порядка сообщений и загрузки истории вокруг сохранённого сообщения.
- В README описано восстановление позиции чтения.

## 2026-11-10

- При входе в комнату отображаются последние 50 сообщений, а поле ввода получает фокус.
- Добавлена кнопка «Загрузить более старые» с подгрузкой истории без смещения текущей позиции.
- API поддерживает выборку предыдущей страницы сообщений по ID (`before`); добавлены проверки пагинации и ограничения начальной выборки.
- README обновлён в соответствии с новым поведением чата.
